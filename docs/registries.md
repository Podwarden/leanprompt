## Anthropic's plugin directory (claude.ai)

One listing reaches claude.ai, Cowork and Claude Code. Sources: [Submit your plugin](https://claude.com/docs/plugins/submit), [Publish and distribute a plugin](https://code.claude.com/docs/en/plugins/publish.md), [pre-submission checklist](https://claude.com/docs/plugins/pre-submission-checklist.md), [Anthropic Software Directory Policy](https://support.claude.com/en/articles/13145358-anthropic-software-directory-policy).

Done in the repository:

- [x] The plugin folder is `plugin/`, generated by `npm run build:forms`: `.claude-plugin/plugin.json` (name, description, version, author, homepage, repository, licence, keywords, `icon`), `.claude-plugin/icon.png`, a README that says what the plugin runs, sends and fetches, LICENSE, LICENSE-DOCS.md, NOTICE.md and `skills/`. 51 files, the largest the icon (32 KiB); no symbolic links, submodules, Git LFS files or `package.json`.
- [x] `claude plugin validate --strict plugin` and `claude plugin validate --strict .` pass with no directory warnings (Claude Code 2.1.332).
- [x] Installed from a local marketplace (`claude plugin marketplace add <checkout>`, then `claude plugin install leanprompt@leanprompt`): the installed copy is `plugin/`. With `claude --plugin-dir plugin`, `/leanprompt` lists the commands.

The owner:

1. Use a claude.ai account on a paid plan (Pro, Max or Ultra; on Team or Enterprise, an Owner), with a GitHub account that can push to `Podwarden/leanprompt` connected on claude.ai in that organization.
2. Open [claude.ai/directory/manage](https://claude.ai/directory/manage), select **Submit new**, then **Plugin bundle**.
3. Source: **Repository** `https://github.com/Podwarden/leanprompt/tree/main/plugin` (fills in **Plugin path** `plugin`; without it the portal validates the whole repository and blocks it), **Branch or tag** empty (follows `main`). Select **Validate**; fix every blocking finding in the repository, push, and validate again.
4. Listing details: read from `plugin/.claude-plugin/plugin.json` and `plugin/README.md`; check them, change nothing in the portal. The icon is `plugin/.claude-plugin/icon.png`, and the first icon saved is the listing icon for good.
5. Data handling: reads or stores personal data, no; sends data to other services, no; keeps data, no; intended for people under 18, no.
6. Compliance: a contact email Anthropic can reach; select all four acknowledgements.
7. Review and submit: keep **GitHub push webhook**, then **Submit for review**; set up push updates if you have admin access to the repository.
8. When the version passes, select **Publish**. Later releases: bump the version, push to `main`; the directory picks the commit up.

## Cursor marketplace

Cursor plugins are git repositories with a `.cursor-plugin/plugin.json` manifest; every plugin must be open source and every update is reviewed. Sources: [cursor.com/docs/plugins](https://cursor.com/docs/plugins), [plugins reference](https://cursor.com/docs/reference/plugins), the manifest schema in [cursor/plugins](https://github.com/cursor/plugins/blob/main/schemas/plugin.schema.json).

Done in the repository:

- [x] `.cursor-plugin/plugin.json` is generated by `npm run build:forms`, with only fields in Cursor's schema: name, displayName, description, version, author, homepage, repository, licence, keywords, `logo` (`plugin/.claude-plugin/icon.png`) and `skills` (`./plugin/skills/`, the same seven skills as the Claude plugin; it replaces Cursor's default scan of `skills/`).

The owner:

1. Test it locally: copy the repository (or link a checkout) to `~/.cursor/plugins/local/leanprompt`, run **Developer: Reload Window**, open **Customize** and check that the seven skills load; type `/leanprompt`.
2. Signed in to Cursor with the account that will own the listing, open [cursor.com/marketplace/publish](https://cursor.com/marketplace/publish) and submit the repository `https://github.com/Podwarden/leanprompt`, with the name, description and logo from [What to paste](#what-to-paste).
3. Each later release is reviewed again; bump the version and push to `main`.

## skills.sh

skills.sh is a leaderboard of skills installed with the `skills` command line tool (`npx skills add <owner>/<repo>`), ranked by that tool's anonymous install counts; it has no form. Sources: [skills.sh](https://skills.sh), [vercel-labs/skills](https://github.com/vercel-labs/skills), [Vercel's announcement](https://vercel.com/blog/introducing-skills).

- [x] `npx skills add Podwarden/leanprompt --list` (skills 1.9.0, run on 2026-11-26 against the published repository) lists the seven skills: generation-economy, leanprompt, llm-call-audit, lmwarden, measure-loop, prefill-cache, prompt-diet. `skills/_template` has no `SKILL.md` and is not listed; the copies in `plugin/skills/` are not listed twice, because the tool reads `skills/` first and drops later skills with the same name.

The owner:

1. Nothing to submit: the repository appears on skills.sh after people install from it with `npx skills add Podwarden/leanprompt`.
2. If it does not appear after installs, ask on the [vercel-labs/skills](https://github.com/vercel-labs/skills) issue tracker (a third-party guide says so; confirm at [skills.sh/docs](https://www.skills.sh/docs)).
3. Where the listing has text, say that `skills` copies the skill folders only; `npx leanprompt install` also adds the OpenCode command and the `AGENTS.md` block.
